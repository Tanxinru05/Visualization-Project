#📋 Overview

This repository contains two powerful Google Sheets management tools designed for HR professionals and organizational development teams:

1. **HR Control Tool** 
A comprehensive membership and HR management system that helps you:
- Track member databases and lifecycle
- Monitor recruitment funnels (MXP - Member Experience Pipeline)
- Analyze member engagement and attendance
- Manage advancement opportunities (Summer/Winter ADV)
- Generate HR dashboards and analytics

✨ Key Features
### HR Control Tool
- 📊 **MX Dashboard** - Visual funnel analysis for member experience
- 👥 **HR Dashboard** - Comprehensive entity overview
- 📈 **Analytics** - Detailed member status tracking
- ✅ **Attendance Tracking** - Monitor participation in activities
- 🎓 **Advancement Management** - Track career progression opportunities
- 🗄️ **Dual Database System** - Organized member information storage
