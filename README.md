## 📋 Overview

This repository contains two powerful Google Sheets based management tools designed for HR professionals and organizational development teams:

### 2. **Organizational Development (OD) Tracker**
A sophisticated organizational health measurement system featuring:
- Multi-dimensional development indices (HDI, XDI, MDI): Metrics defined to measure an organizational overall growth
- Entity health and growth tracking
- Market and exchange development metrics
- Visual dashboards and scoring systems
- Automated calculations and benchmarking

## ✨ Key Features
### OD Tracker
- 🎯 **3 Core Indices**:
  - HDI (Health Development Index)
  - XDI (Exchange Development Index)
  - MDI (Market Development Index)
- 📊 **Visual Dashboards** - Summary scores and performance visualization
- 🏆 **Tiering & Clustering** - Entity classification systems
- 📈 **Cumulative Tracking** - Historical performance analysis
- 🤖 **Automation Templates** - Streamlined data processing
